= Query reference
:sourcedir: ../

These queries target Guillotine 9 on Enonic XP 8.1+.
POST to `/api/com.enonic.app.guillotine:graphql`, not a `/site` endpoint.
Each query selects `guillotine(project: "intro", branch: "master", scopeKey: "/")` directly.
When testing in Content Studio's Query Playground or another GraphQL client, copy only the query text between the TypeScript backticks. The person list needs no variables; the person and person-movies queries need only `personId`.

Use `draft` only for an authenticated editorial test. The SPA reads published `master` content anonymously.

== Person details

.src/queries/Person.ts
[source,TypeScript]
----
include::{sourcedir}src/queries/Person.ts[]
----

Supply `personId` as the only variable. For the Intro sample dataset:

[source,json]
----
{

  "personId": "a8b374a2-c532-45eb-9aa1-73d1c37cd681"
}
----

The response is under `data.guillotine.get`.
Rich-text internal links and images in `processedHtml` are placeholders: the custom renderers resolve them using the structured `links` and `images` entries.
The query preserves page-link query strings and fragments, media download intent, and responsive image candidates.
