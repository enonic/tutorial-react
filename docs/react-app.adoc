= Creating the React app
:sourcedir: ../
:imagesdir: media/

In this chapter you will create a React application with TypeScript, connect it to the Enonic API, and add routing.

== Task: Create the project

. *Scaffold the app*. With the sandbox running, open a new terminal window and run this command:
+
[source,Terminal]
----
npm create vite@9 react-enonic -- --template react-ts
----
+
This creates a Vite project with React and TypeScript in a folder called `react-enonic/`.
+
. *Install the dependencies*:
+
[source,Terminal]
----
cd react-enonic

npm install react-router-dom sass @enonic/react-components
----
+
This installs the dependencies of the project template, and adds:
+
* `react-router-dom` for routing between the pages of the application
* `sass` for the stylesheets used in this tutorial
* `@enonic/react-components` for rendering rich text from Enonic
+
. *Remove the files you will not need*. Delete `src/App.css` and the `src/assets/` folder.

== Task: Connect to the API

The application runs in the browser and fetches content directly from https://developer.enonic.com/docs/guillotine[Guillotine]. During development, the application and Enonic run on different ports. To keep all requests on the application's own origin, Vite will forward them to Enonic.

. *Add a proxy*. Replace the contents of `vite.config.ts` with the following:
+
.vite.config.ts
[source,TypeScript]
----
include::{sourcedir}vite.config.ts[]
----
+
Vite now forwards every request starting with `/api` to the sandbox. This covers both the GraphQL endpoint and the images it refers to. To use an Enonic instance on another address, set `+ENONIC_URL+` in `.env`.
+
. *Set the endpoint*. Create a file called `.env` in the root of the project:
+
..env
[source,properties]
----
VITE_GUILLOTINE_URL=/api/com.enonic.app.guillotine:graphql
----
+
The value is relative, so the browser sends requests to the application's own origin, where the proxy picks them up.

WARNING: Vite includes `+VITE_+` variables in the code sent to the browser. Never use them for credentials or other secrets.

NOTE: The proxy only exists during development. In production, either route `/api` to Enonic on the host serving the application, or build with an absolute endpoint URL and configure https://developer.enonic.com/docs/guillotine/stable/configuration[CORS in Guillotine].

== Task: Start the app

. *Start Vite* from the project folder:
+
[source,Terminal]
----
npm run dev -- --port 3000
----
+
. *Open the app* at http://localhost:3000[http://localhost:3000]. It shows the start page of the project template:
+
image::react-app.png[width=75%]

Leave Vite running. It updates the page in the browser whenever you change a file.

----

----
+
. *Replace the contents of `src/App.tsx`* with a router that has a single route:
+
.src/App.tsx
[source,TypeScript]
----
import './App.sass';
import {Route, BrowserRouter as Router, Routes} from 'react-router-dom';

export default function App() {
  return (
    <Router>
      <Routes>
        <Route path="*" element={<p>Hello router!</p>}/>
      </Routes>
    </Router>
  );
}
----
+
. *Verify the result*. Your browser should now display the text `Hello router!`.
