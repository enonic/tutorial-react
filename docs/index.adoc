This is a step-by-step tutorial on building a client-side https://react.dev/[React] application that renders structured content from Enonic. The application fetches published content through {guillotine-docs}[Guillotine], Enonic's GraphQL API, and uses the `@enonic/react-components` library to render rich text.

TIP: *Just want to see the result?* <<demo#,Run the demo>> to try the finished application without going through the chapters.

== Intro

Enonic can be used as a headless CMS: editors manage content in Content Studio, and your application reads it through an API. In this tutorial the application is a single-page application built with Vite, which runs entirely in the browser.

When you are done, the application lists persons like this:

image::person-list.png[The person list as a grid of photos,width=75%]

You will complete the following steps:

* <<enonic-setup#,Set up Enonic>> with sample content, and try out the GraphQL API
* <<react-app#,Create a React app>> and connect it to Enonic
* <<list#,List persons>> fetched from the API
* <<details#,Show the details>> of a single person
* <<rich-text#,Render rich text>>, with control over links and images
* <<macros#,Render macros>> using your own React components

The tutorial covers delivery of published content. If you need server-side rendering or live preview in Content Studio, have a look at the {nextjs-tutorial}[Next.js tutorial] instead.

[#prerequisites]
== Prerequisites

You should be familiar with React and TypeScript. If Enonic is new to you, complete the https://developer.enonic.com/learn/intro[introduction to Enonic] before starting this tutorial.

To follow this tutorial you will need:

* https://nodejs.org/[Node.js] 24 or newer, with npm
* Your favorite code editor

You will install the Enonic CLI in the first chapter.
